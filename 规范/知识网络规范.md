# 知识网络规范 v1

> 定于 2026-11-24，由「数据库知识网络」定型。
> 参考实现：`mindmap/database/index.html`
> 以后所有知识点上传 GitHub，都按这份来。

---

## 一、一条硬要求

**点开任何一个知识点，必须能看到代码图。**

- 深色代码块 + 语法高亮（关键字蓝 / 字符串绿 / 数字黄 / 注释灰）
- 概念图或流程图（如 SQL 执行顺序、ER 关系、调用链）
- 纯概念课允许没有代码块，但**不许整页都是纯文字**

## 二、页面必须有的六样东西

| # | 元素 | 说明 |
|---|---|---|
| 1 | 顶部 tab | 主页 / 博客 / 知识地图 / 前端 / Vue3 / Python / Python 后端 / 数据库 / 机器学习 |

| 6 | 学习标记 | 点圆圈标记已学，存 localStorage，可导出 / 导入 |

## 三、知识点怎么写

**每条 = 要点 + 一句话解释**，用 ` —— ` 分隔：

```
"GROUP BY —— 分组查询，配合聚合函数"
"HAVING —— 过滤分组后的结果，WHERE 在分组前"
```

**必须写「解决什么问题 / 坑在哪」**，不能只写名词：

```
√ 坑 —— allow_origins=["*"] 不能和 credentials 同用
√ 注意 —— 不排序时分页结果不稳定
× 分页查询
```

每集 5–6 条，**最少 3 条**。

---

## 四、代码图怎么写

每个语法点给一段能直接跑的代码，带注释：

```sql
-- 分页：LIMIT 起始, 条数
SELECT * FROM tb_user LIMIT 0, 10;    -- 第 1 页
SELECT * FROM tb_user LIMIT 10, 10;   -- 第 2 页

-- 起始 = (页码 - 1) * 每页条数
```

- 短：3–8 行，别贴整屏
- 注释写「为什么」，不是「这是什么」
- 不编造：概念课放流程图代替

## 五、数据 schema

一个系列 = 一个目录，数据在 `content/content.json`：

```jsonc
{
  "meta": {
    "title": "数据库 · MySQL 知识网络（46 集）",
    "brand": "数据库 · MySQL",
    "brand_sub": "黑马 · 46 集 / 6 章",
    "desc": "页面描述（meta description）",

    "active_tab": "数据库"         // 导航高亮哪个

  "learned": [5, 6, 7],           // 默认打勾的集

      "eps": [

    }
  ]

```

## 六、四道门禁

```powershell
# 1. 生成
python 工具/新建知识网络.py --name redis --bv BV1xxx --chapter "01:基础:1-30"

# 2. 填内容（pts / code），再渲染
python 工具/新建知识网络.py --name redis --bv BV1xxx --chapter "01:基础:1-30" --build-only

# 3. 体检
python 规范/知识网络体检.py --content mindmap/redis/content/content.json --html mindmap/redis/index.html
```

| 门禁 | 查什么 |
|---|---|
| 内容 | 每集有知识点、不少于 3 条、无空章、集号不重复、写法用 ` —— ` |
| 代码 | 代码图覆盖率（< 40% 提醒） |
| 渲染 | 占位符替换干净、JS 语法通过、三视图/抽屉/高亮/看板都在 |
| 链接 | 分集链接成形、BV 号对得上 |

## 七、发布前三件事

1. **补全站入口**：新页面要加进其它所有页面的顶部导航**和页脚**，漏一处就有人进不来
2. **线上验证**：`curl` 拿 HTML，确认关键字符串在
3. **手机宽度**：不横向溢出

判据只有一条：周日的验收物达成了才算这周过。落后超过 2 天就砍加分项保保命线， 别想着下周补回来。

这个站怎么用

纯静态站，没有框架、没有构建步骤：数据在 data/，逻辑在 js/， 双击 index.html 就能打开，推到 GitHub 就自动变成网址。

1. 每天要做的最小动作

  • 做完一个任务 → 在「进度」或「计划」里打勾
  • 写一篇笔记 → 在 data/notes.js 的数组里加一段
  • 提交一次 Git（commit message 写清做了什么）

2. 进度怎么跨设备

  1. 在页面里勾任务，点 导出进度 下载 progress.js
  2. 用它覆盖仓库里的 data/progress.js
  3. 提交推送，等一分钟 Pages 重新部署

什么时候需要这么做：换电脑、清浏览器数据之前、每周日复盘的时候。

3. 加一篇笔记

打开 data/notes.js，复制一个 { ... } 块，改四样东西：

{
  "id": "n-20261027-1",        // 唯一，别和别的重复
  "date": "2026-10-27",        // 决定它归到哪个月
  "category": "FastAPI",       // 决定左侧分类筛选
  "title": "day1：第一个接口",
  "tags": ["路由", "Pydantic"],
  "content": "正文，支持 Markdown"
}

也可以在 GitHub 网页上直接编辑这个文件，提交后自动部署。

4. 部署（只需做一次）

仓库 → Settings → Pages → Source 选 Deploy from a branch， Branch 选 main、目录选 / (root)，保存。 等一分钟，网址就是 https://你的用户名.github.io/仓库名/。

5. 改配色 / 改内容

  • 主色：css/style.css 最上面的 --accent
  • 计划任务：data/plan.js
  • 笔记：data/notes.js

6. 三个页面各自管什么

  • 主页（这一页）：进度勾选、8 周计划、笔记速览
  • 博客：把 data/notes.js 当文章读，按月份和分类归档， 每篇文章有独立链接（blog/#p/笔记id），可以直接发给别人
  • 知识地图：节点和依赖写在 mindmap/data.js， 点节点看说明与验收标准，手机上自动切成「按阶段」列表

# 视频截图放这里

案例页（`/mindmap/cases.html`）里每个案例都有一块「视频截图」的位置，图片从这里按 **P 号** 取：

```text
shots/
├─ p31.png    成年人判断
├─ p40.png    猜数字
├─ p61.png    ATM
└─ …
```

## 怎么加

1. 打开对应集数的视频，暂停在案例题目 / 运行结果那一帧。
2. `Win + Shift + S` 截图，存成 PNG。
3. 按 `p<集数>.png` 命名，丢进这个文件夹，刷新页面就会自动显示。

没有图片的案例会显示一块虚线占位，不影响页面使用。

建议宽度 1000–1400px，体积控制在 300KB 以内，仓库会轻一些。

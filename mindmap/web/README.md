## 两个视图

- **全链路图**（默认）：三门课三条横向卡片链，每章一张卡，卡内是该集列表，卡片之间有箭头。
- **思维导图**：中心「前端知识」向左右发散，蓝色 HTML+CSS、绿色 JavaScript、橙色 ES6，每个章节一片叶子。
- 右下角黑色胶囊按钮随时切换；`?view=map` 可直接进思维导图。

## 交互

- 点章节标题 / 叶子 / 卡片里的 `?`：弹出详情卡（本章定位 + 分集列表）。
- 点某一集：详情卡显示这一集在讲什么、示意图、重点清单，底部可标记已学、跳 B 站分 P。
- 已学 39 集来自《前端 2.5 天速通表》，绿色；自己改的进度存 localStorage。
- 顶部筛选：全部 / 只看已学 / 只看待学；搜索支持章节名和集名。
- 导入标记 / 导出标记：进度导出成 JSON，换设备导入即可。
- 思维导图支持滚轮缩放、拖拽平移、「适应窗口」回全景。
- 深链：`?f=done` 已学视图，`?view=map&open=A-138` 直接打开某一集。

## 用法

- 四层树：前端基础 → 课程 → 章节 → 集；点章节展开/收起，点集看详情卡
- 详情卡：本章定位 + 已学集的逐集要点 + 示意图 + 重点清单，底部跳 B 站对应分 P
- 顶部筛选：全部 / 已学 / 待学；加 ?f=done 直达已学视图，?open=A-138 直达某一集
- 已学 39 集来自《前端 2.5 天速通表》，绿色标记；点详情卡里的「标记已学」可自己改，进度存 localStorage
- 另一视图：右下角「切到长链路图」，三门课各一条卡片链
